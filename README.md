# Flores amarillas

Un jardín nocturno en CSS con un mensaje para el día del amor y la amistad.

**Ver:** https://joshertmr.github.io/flores-amarillas/

El mensaje acepta dos parámetros opcionales en la URL:

- `?para=Nombre` — cambia el encabezado a «Para Nombre»
- `?de=Nombre` — añade una firma al final

Ejemplo: `https://joshertmr.github.io/flores-amarillas/?para=Ana&de=Josué`

## Créditos

La animación de las flores y los corazones parte del pen
[Flores y corazones](https://codepen.io/mabelolivera10/pen/mdozBbM) de
**Mabel Olivera**, publicado bajo licencia MIT (ver `LICENSE.txt`).
La paleta, la tipografía, el mensaje, la composición responsive y la marca
de agua son modificaciones sobre ese trabajo.
